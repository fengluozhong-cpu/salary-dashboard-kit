# 数据格式说明

两张 CSV 全部使用 **UTF-8 with BOM（`utf-8-sig`）**，便于 Excel 直接打开不乱码。`dashboard.py` 按**固定列序号**读取，列顺序不能调整；列名仅作参考。

## 1. `工资年度汇总.csv`（10 列）

| 序号 | 列名 | 类型 | 说明 |
|---|---|---|---|
| 0 | 类型 | 文本 | `月度` 或 `年度`；**看板只读 `月度` 行** |
| 1 | 期间 | 文本 | 月度用 `2026-01`，年度用 `2026` |
| 2 | 税前工资收入 | 数值 | 可带千分位逗号 |
| 3 | 养老保险 | 数值 | |
| 4 | 医疗保险 | 数值 | |
| 5 | 失业保险 | 数值 | |
| 6 | 住房公积金 | 数值 | |
| 7 | 社保合计(税前支出) | 数值 | 通常为 3+4+5+6 |
| 8 | 个人所得税(税费支出) | 数值 | |
| 9 | 税后工资 | 数值 | 看板收入口径取这一列 |

示例（dummy）：

```
类型,期间,税前工资收入,养老保险,医疗保险,失业保险,住房公积金,社保合计(税前支出),个人所得税(税费支出),税后工资
月度,2026-01,"20,000.00","1,600.00","400.00","100.00","2,400.00","4,500.00","1,050.00","14,450.00"
年度,2026,...
```

> 金额写成 `20000` 或 `"20,000.00"` 都能读；空值按 0 处理。

## 2. `bills_parsed.csv`（8 列）

| 序号 | 列名 | 类型 | 说明 |
|---|---|---|---|
| 0 | 来源 | 文本 | 展示名，与 `profiles/sources.json` 的 `label` 一致 |
| 1 | 月份 | 文本 | `YYYY-MM` |
| 2 | 应还金额 | 数值 | 空值按 0，不参与支出合计 |
| 3 | 最低还款额 | 文本/数值 | **L1 展开项** |
| 4 | 账单周期 | 文本 | **L1 展开项** |
| 5 | 用电量 | 数值 | 电费类填，其余留空；**L1 展开项** |
| 6 | 状态 | 文本 | 如 `已提取` / `需OCR`；**L1 展开项** |
| 7 | 原始文件 | 文本 | 文件名，用于回溯；**L1 展开项** |

示例（dummy）：

```
来源,月份,应还金额,最低还款额,账单周期,用电量,状态,原始文件
示例信用卡 A,2026-01,1200.0,"120.00",账单周期2026-01-01,,已提取,2026-01.html
示例电费,2026-01,128.0,,"",180.0,已提取,2026-01.html
```

## 3. 输出

- `收支统一看板.html`：单文件、自包含、离线可开，内嵌完整 JSON（点「导出数据 JSON」可另存）。
- `看板数据.json`：可选导出，结构与内嵌 JSON 一致，便于后续人工对接多维表格。

## 4. dummy 数据

包内 `data/` 的 2025 + 2026 两年（24 个月工资 + 72 份账单）**全部为规整虚构值**，不含任何真实账户、姓名或金额。`data/IS_DUMMY.txt` 存在时看板会显示「演示数据」水印。接入真实数据前请删除该标记并替换两张 CSV。
